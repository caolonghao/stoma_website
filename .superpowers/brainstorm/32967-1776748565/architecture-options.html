双端系统架构选项

目标：医生端 + 患者端一起交付，但一期尽量减少不必要的复杂度。

推荐方向

同一个 Web 系统，按角色区分入口与权限

医生端和患者端共用一套后端、数据库、文件存储与认证体系，只是在前端路由和权限上分为两套工作区。

为什么适合这期

你们是单科室场景，首期重点是尽快打通业务闭环，不需要一开始就拆成多服务或多应用。

A. 单体双端 Web 应用
推荐
医生端 Web
患者端 Web
↓

  • 权限边界清晰，后端模型统一
  • 后续 AI 接口接入成本低

  • 更适合多人并行开发
  • 部署与联调复杂度稍高
C. 医生端与患者端分别做系统

  • 隔离性最好
  • 工程与权限治理更复杂
  • 对一期 MVP 来说偏重
